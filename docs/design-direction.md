# Inside the engineering studio

Implementing the user's detailed approved brief directly. Main design decision: a continuous graphite workstation doubles as a product exhibition, with custom machined monitor, satin metal, controlled lime rim lighting and an autonomous chrome ribbon. Persistent native-scroll 3D is preferable to isolated canvases because the brief calls for continuity and integrated-GPU practicality; a wholly WebGL UI would compromise accessible content.

Palette: #080a09 / #141714 / #f0f2ec / #a8afa4 / #c8ff3d. Space Grotesk display and Inter text. Oversized editorial title, fine technical labels, ruled section framing and asymmetric composition. No gate, no forced custom cursor, no auto audio.

Home: left identity and actions, right workstation. Work: selected project's authentic screen and accessible HTML exhibition list. Services: HTML selectors focus engineered modules. About/skills: same studio changes framing behind biography, real portrait and categorized technical skills. Contact: quieter studio and full accessible form. Case studies: server-rendered project-specific metadata, gallery and evidence-based narrative; direct refresh works.
